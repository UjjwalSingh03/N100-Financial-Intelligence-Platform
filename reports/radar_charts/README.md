# Radar Chart Artifacts

This directory contains Sprint 3 peer-analysis radar chart artifacts.

- `HDFCBANK_radar.png` is a generated radar-chart artifact.
- The project generator is `scripts/peer_reports.py`.
- Full radar output is generated to `reports/radar_charts/` by running the generator against the validated database and peer-group data.

Expected naming convention: `<COMPANY_ID>_radar.png`.
